## 3. What this pilot establishes about the method

**The two-step design works and is necessary.** Separating (i) record existence from (ii) holder-name identity produced materially different answers within single claims: MU-1, MY-1, SC-1, SC-2, and AE-1 all pass name-level while remaining unverifiable at number level; MU-2 fails step (i) as claimed while a differently-named holder passes a related step (ii). A one-step "is it licensed?" check would have collapsed these distinctions.

**A third layer emerged: number-level verification is a distinct step, not a sub-part of step (i).** Five of eleven verifiable claims could not be number-checked because the register publishes no numbers. The protocol's documented Seychelles limitation was instantiated exactly as predicted (SC-1: names published, SD numbers not; SD089 confirmed as UNVERIFIABLE-TODAY, not as absent). The same structural gap exists in three further registers not previously documented:

- FSC Mauritius OPR — no licence numbers displayed, no number search (MU-1, MU-2);
- Labuan FSA directory — no numbers, no dates (MY-1);
- UAE CMA register — displays its own record identifier (CP-series), not the number format claimed on pages (AE-1);
- FSCA — number verifiable, but the trading-name field can be blank, leaving trading-name claims unverifiable (ZA-1).

**Register-infrastructure fragility is a live methods issue.** ASIC's legacy interface was down for scheduled maintenance during the check (fallback register available); ASIC and FSCA results have no stable deep links (application/POST interfaces), so the protocol's register-URL requirement needs a convention for "tool URL + search term + date" citations, which this pilot used.

**The taxonomy's B sub-codes are usable but need one clarification.** B-portfolio and B-mis-anchor both applied cleanly. anchor-no-number was applied here to the register-side condition (authority anchor present, no number verifiable because the register publishes none); if the frozen definition intends the page-side condition (anchor displayed with no number claimed), the MU-1/MY-1/SC-2 taggings should be recut — flagging for protocol-note resolution, not re-coding.

**Registers can supply operative evidence, not just licence evidence.** Three register entries name websites (ASIC → atfx.com/en-au; FSA Seychelles → xs.com and zfx.com), which bears directly on the OE step and should be formalised as admissible OE evidence alongside OE-1.
